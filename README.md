# MediCore — Smart Hospital Management & Clinical Information System

Full-stack hospital management system (React + Node.js + Oracle) demonstrating core DBMS concepts — ER modeling, normalization to BCNF, PL/SQL procedures/functions/triggers, ACID transactions, concurrency control, indexing, query optimization, and recovery — alongside a real, working clinical workflow.

**Status:** 🚧 In progress (Phase 0/1 — environment setup & schema design)

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Styling | CSS / Tailwind |
| Backend | Node.js + Express.js |
| Database | Oracle Database (XE) |
| DB Programming | SQL + PL/SQL |
| API | REST |

## Repo Structure
/db -> schema.sql, seed.sql, PL/SQL procedures/functions/triggers
/backend -> Node.js + Express REST API
/frontend -> React application
/docs -> ER diagram, normalization writeup, phase gate artifacts, final report
